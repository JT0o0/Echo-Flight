# 盲飛 Echo Flight

一款用回聲定位飛行的洞穴小遊戲。你是一隻在漆黑洞穴裡飛行的蝙蝠，看不到牆壁，只能靠自己的叫聲和回聲找出路。

整個遊戲只有一個 HTML 檔，不需要安裝或建置，用瀏覽器打開就能玩。

## 快速開始

1. 下載或 clone 這個 repo。
2. 用瀏覽器打開 `盲飛蝙蝠.html`。
3. 按「起飛」開始。

字體從 Google Fonts 載入。離線時會改用系統字體，遊戲照常運作。

## 遊戲介紹

洞穴裡伸手不見五指，畫面上不會畫出任何牆壁。每次發聲，聲波會往四周擴散，打到洞壁或岩塊後留下回聲點。你看到的洞穴形狀全都來自這些回聲。

回聲只會停留幾秒，所以你要記住剛剛「聽到」的地形，再安靜地飛過去。

- **回聲顏色代表距離**：越近越紅，越遠越紫。
- **安靜越久，倍率越高**：每安靜 1.5 秒倍率加一，最高 ×5，一發聲就歸零。
- **發聲要消耗聲能**：聲能會慢慢回復，不夠時無法發聲。
- **飛蛾**：黑暗中偶爾閃一下的琥珀色小點，吃到可以補聲能、加分。
- **越飛越難**：飛得越遠，速度越快、洞穴越窄，障礙也越多。

撞上洞頂、洞底、鐘乳石、石筍或岩塊，遊戲就結束。

## 操作方式

| 動作 | 電腦 | 手機或平板 |
|---|---|---|
| 上下移動 | 移動滑鼠，或按 <kbd>↑</kbd> <kbd>↓</kbd> / <kbd>W</kbd> <kbd>S</kbd> | 在畫面上拖曳 |
| 發聲 | 按住 <kbd>空白鍵</kbd> 或滑鼠左鍵蓄力，放開送出 | 按住右下角「聲」鈕蓄力，放開送出 |
| 開始、重來 | 點按鈕，或按 <kbd>Enter</kbd> / <kbd>空白鍵</kbd> | 點按鈕 |
| 開關聲音 | <kbd>M</kbd> 鍵或右上角喇叭按鈕 | 右上角喇叭按鈕 |

蓄力越久，聲波傳得越遠、回聲停留越久，但也越耗聲能。手機建議橫放，前方的視野比較寬。

## 計分

- 每飛 1 公尺得 1 分，再乘上當下的倍率。
- 每隻飛蛾 20 分，同樣乘上倍率，並回復 20 聲能。
- 最佳分數存在瀏覽器的 localStorage，不會上傳到任何地方。

## 小技巧

- 開局先送一記蓄滿的聲波，看清楚前方再安靜飛一段。
- 戴耳機玩：洞頂的回聲音高比較高、洞底比較低，前方的回聲偏向右聲道。
- 飛蛾就算你不發聲也會偶爾閃一下，可以靠閃光找到牠們。

## 技術

| 項目 | 使用的技術 |
|---|---|
| 遊戲畫面 | Canvas 2D |
| 介面 | HTML、CSS |
| 音效 | Web Audio API 即時合成，沒有任何音檔 |
| 存檔 | localStorage（最佳分數、靜音設定） |
| 外部依賴 | 只有 Google Fonts，沒有框架或建置工具 |

需要支援 Canvas 2D 和 Web Audio API 的現代瀏覽器。系統開啟「減少動態效果」時，遊戲會關閉畫面震動和背景灰塵。

## 專案架構

```text
.
├── 盲飛蝙蝠.html   遊戲本體，HTML、CSS、JavaScript 都在這個檔案
└── README.md
```

`盲飛蝙蝠.html` 裡的 JavaScript 用 `// ---------- 名稱` 註解分成以下區塊：

| 區塊 | 負責內容 |
|---|---|
| `tuning` | `CONFIG`：所有遊戲平衡數值 |
| `viewport` | 螢幕座標與世界座標的換算 |
| `cave` | 生成洞穴地形、障礙物和飛蛾 |
| `sonar` | 射線偵測、發出聲波 |
| `audio` | 合成音效、環境音、靜音 |
| `game flow` | 開始、蓄力、碰撞、死亡、結算 |
| `input` | 鍵盤、滑鼠、觸控 |
| `simulation` | 每一幀的遊戲邏輯 `update()` |
| `rendering` | 每一幀的畫面 `render()` |
| `HUD` | 把遊戲數值同步到介面 |
| `boot` | 初始化與主迴圈 |

### 運作方式

- **狀態**：遊戲狀態集中在物件 `S`，流程是「開始頁 → 遊戲中 → 墜落 → 結算 → 遊戲中」，目前所在的階段記在 `S.mode`。
- **主迴圈**：每一幀依序執行 `update()`、`render()`、`hud()`。
- **無限洞穴**：洞頂和洞底各用一個陣列記錄高度，前方持續生成，後方持續丟棄。
- **聲納**：發聲時從蝙蝠往 360° 發出射線，記下每條射線打到牆壁的位置。這些回聲點用世界座標保存，畫面捲動時會留在原地，等聲波傳到才亮起，再慢慢淡出。牆壁本身從來不會被畫出來。

## 調整遊戲平衡

所有平衡數值都集中在檔案開頭的 `CONFIG`，每個值都有中文註解。改完存檔、重新整理瀏覽器就會生效。

```js
difficulty: {
  startMeters: 40,    // 飛到這裡才開始變難
  rampMeters: 1400    // 再飛多遠達到最高難度
},
```

常見的調整：

| 想要的效果 | 調整的值 |
|---|---|
| 前期輕鬆一點 | 調大 `difficulty.startMeters` |
| 難度上升慢一點 | 調大 `difficulty.rampMeters` |
| 發聲便宜一點 | 調小 `energy.pingCharge` |
| 倍率累積快一點 | 調小 `score.multInterval` |
| 洞穴寬一點 | 調大 `cave.gap` |

- 寫成 `[起點, 終點]` 的值會隨難度或蓄力漸變，寫成 `[最小, 最大]` 的值是隨機範圍。
- HUD 的倍率格數和開始頁的倍率說明，會跟著 `CONFIG.score` 自動更新。
- 調大 `sonar.radius` 時，`world.generateAhead` 也要跟著調大，否則聲波會打到還沒生成的地形。
